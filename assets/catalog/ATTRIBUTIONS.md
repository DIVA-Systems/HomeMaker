# Furniture Catalog Attributions

HomeMaker ships a curated subset of free 3D furniture models from the Sweet Home 3D project.
Models are packaged as SH3F libraries distributed on SourceForge / sweethome3d.com (version 1.9.3).

## Per-item credits

Each entry in `catalog.json` includes `license`, `attribution`, and `creator` fields.
When redistributing or displaying models, retain those credits—especially for CC-BY libraries (Scopia, KatorLegaz).

This curated set contains **124** furniture pieces.
